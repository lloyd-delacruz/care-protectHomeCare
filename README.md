# Care & Protect Homecare

A website for Care & Protect Homecare, built with React, TypeScript, and Vite.

## Tech stack

- React 18
- TypeScript
- Vite
- React Router

## Getting started

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

The site runs at `http://localhost:5173` by default.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview the production build locally |
| `npm run typecheck` | Type-check without emitting output |

## Project structure

```
.
├── src/            # Application source
├── public/         # Static assets served as-is
├── Asset/          # Brand assets and imagery
├── dist/           # Production build output
├── index.html      # Vite entry HTML
└── vite.config.ts  # Vite configuration
```

## Building for production

```bash
npm run build
```

The compiled output is written to `dist/` and can be served by any static host.
